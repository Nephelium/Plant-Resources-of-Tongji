# 植物照片与每日相识

## 照片逐张浏览

原有植物照片有许多是上下拼接的长图。此轮为 425 份影像建立 797 个独立画面的区域索引，页面通过原图视窗一次呈现一张照片。没有改写原始照片或调查记录，画面里的署名和水印随原照片保留。

- 分类页、植物档案、检索卡片及首页相识卡片共用 `PlantGallery.vue`。
- 卡片展示单张照片，左右切换或滑动，点击照片打开大图。
- 档案内照片完整显示，竖幅照片以深绿色底衬托。大图保留完整构图，可放大两倍并滚动看细节。
- 大图支持按钮、左右方向键和手机滑动，Esc 或关闭按钮返回。关闭后恢复页面滚动与原焦点。
- 切换物种、离开页面或组件卸载时，清理滚动锁、对话框和观察器。
- 页面按照片是否进入视窗加载原始影像，缺照片时显示对应物种的语义占位。

典型照片数已人工对照原图：芭蕉 2 张、水杉 3 张、玉兰 5 张、八角金盘 2 张、银杏 3 张、鹅掌楸 5 张、石榴 4 张、黄鹌菜 6 张。区域索引的所有坐标均检查位于对应原图范围内。

实现中，`PlantImage.vue` 以 SVG `viewBox` 选取原始照片范围，图片本身仍是原来的 JPEG/PNG。布局改变时直接缩放视窗，无需生成或上传另一套植物照片。

## 今日遇见与随机卡片

- 从实际调查数据中有照片的物种选取，排除空名称。
- 首页插画旁的植物卡片和地图侧栏的今日遇见共享每日三种植物。
- 按北京时间日期生成稳定的每日选择，当天刷新保持一致。页面定时检查日期，重新回到页面时也检查一次。
- 熟悉的校园，新的相识每次进入重新抽取四种植物，并避开今日三种。
- 换一组会避开当前四种，在资料足够时得到另一组，卡片科名与学名来自真实数据。

## 文件与维护

- [PlantGallery.vue](../src/components/PlantGallery.vue)：滑动图库与大图查看器。
- [PlantImage.vue](../src/components/PlantImage.vue)：单张影像视窗、按需加载和缺图状态。
- [plant-photo-regions.json](../src/data/plant-photo-regions.json)：原图尺寸与各照片区域。
- [index-photo-regions.py](../scripts/index-photo-regions.py)：只读取原始照片，依据白色分隔线重建索引。需要 Pillow、NumPy，前端运行不依赖 Python。
- [discovery.ts](../src/utils/discovery.ts)：北京时间日期与无重复抽样。
- [verify-gallery.cjs](../scripts/verify-gallery.cjs)：实际浏览器交互检查，共 26 项通过。

更新照片后先运行 `npm run assets:index`，再运行 `python scripts/index-photo-regions.py`。对照原图检查生成区域，尤其检查分隔线不明显的新图片，再核对缩略图、滑动与完整大图。
