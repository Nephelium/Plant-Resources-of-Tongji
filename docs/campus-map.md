# 校园地图维护说明

默认底图由仓库根目录的 `植物地图电子版.pdf` 提取。在线地图仍使用 OpenStreetMap，两种底图共用植物点位。浏览器通过 `tongjiplants_basemap` 保存选择，首次访问默认校园图。

## 原图与网页资源

原 PDF 是一页 8124 × 6070 点的 Illustrator 矢量图，约 32 MB。原文件没有地理参考信息，网页不会直接下载它。

`scripts/build-campus-map.py` 提取 1,389 条道路、建筑、绿地、水面及轮廓路径，排除植物编号图层、调查圆点和左侧图例。输出北向朝上的 `public/maps/campus-light.svg` 与 `campus-dark.svg`，每个文件 538,161 字节。图形沿用原图，不生成新的建筑或道路。

`src/data/campus-map.json` 保存范围、仿射矩阵、源文件 SHA-256、配准残差及 123 处楼名。标签保留 PDF 的楼号和简称，完整原名也保存在元数据中。原图存在重复楼号（例如多个 D19），照原图保留，不据此假定楼号唯一。只有重复植物代码构成的 `D14D14` 等字符串被排除。

浏览器把楼名绘制成独立标签，字号不会随地图无限放大。普通楼名从全校视图开始参与排布，地标优先，放大或平移后重新排列；互相重叠或被地图控件遮挡的标签暂不显示。

## 坐标配准

1. 用原图与原始 GeoJSON 中稀少且唯一的植物编号建立 18 组候选控制点。
2. RANSAC 保留 15 组一致控制点，拟合 PDF 坐标到 EPSG:3857 的仿射变换。
3. 通过原图圆心与调查坐标的双向最近邻迭代细化，最后得到 7,521 对匹配。
4. 用同一变换转换建筑路径、楼名位置与补充植物点。网页植物坐标继续使用经纬度，底图切换不重新计算植物位置。

2026-10-23 生成结果：

| 对照 | 中位残差 | 95% 分位残差 |
| --- | ---: | ---: |
| 15 组编号控制点 | 2.300 m | 5.846 m |
| 7,521 对圆心匹配 | 1.102 m | 2.831 m |

这是相对于原调查数据的拟合残差，换算时采用校园中心纬度。它不代表独立测量的真实地面定位精度。PDF、现有坐标和校园实际情况可能来自不同记录时间。

## 衷和楼东北侧的补充点位

对照发现，原 PDF 在衷和楼东北侧有植物标注，前后端原始 GeoJSON 均缺少这一片。补充仅限 PDF 坐标范围 `[6050, 380, 6720, 980]`，不改写原文件。

- 从原图圆心恢复 503 个点位，涉及 34 个植物中文名。
- 每个点通过字符级坐标读取圈内编号，拆开连在一起的 `M7M7` 等文本。编号中心与圆心的最大偏移为 0.933 PDF 点，生成时要求小于 1.5 点。
- 距已有点不足 8 个 Mercator 米的接缝区域不补入，避免把原图与坐标的小幅偏差误当成缺失点。实际最近间隔记录在元数据中。
- 已有编号的分类、名称与花果期沿用原数据；Q1 黄栌和 Q13 红花碧桃按原 PDF 图例录入，未记载的花果期留空。
- `public/maps/campus-supplement.geojson` 中每条记录保留 `source: campus-pdf`、来源区域及 `pdf_position`。点位弹窗显示 PDF 来源和编号。

静态 API 将原始 15,937 个点与这 503 个点合并，总计 16,440 个点，143 个非空中文名、54 个科。地图、搜索、分类与植物档案使用同一合并结果。动态模式继续读取后端 API，本次未改写后端数据。

## 重新生成与检查

生成工具使用 Python、PyMuPDF、NumPy、SciPy 和 OpenCV。网页运行不依赖这些 Python 库。修改 PDF 或调查文件后，先核对输入，再运行：

```powershell
python scripts/build-campus-map.py
npm run build:static
npm run build:dynamic -- --outDir dist-dynamic
```

脚本会检查控制点数量、配准残差、圆心匹配数量、补充点编号与重复位置。断言失败时应查看源文件和控制点，不直接放宽阈值。当前 503 点是已核对范围的记录数，源图变化后需要重新审阅这一范围。

打开生产预览后运行两个地图专项：

```powershell
npx --yes --package @playwright/cli playwright-cli -s=campus-check run-code --filename=scripts/verify-campus-map.cjs --raw
npx --yes --package @playwright/cli playwright-cli -s=campus-check run-code --filename=scripts/verify-map-theme.cjs --raw
```

检查全校、衷和楼东北侧和局部道路的叠合效果，以及日夜切换、手机展开、楼名遮挡、点位搜索、来源弹窗与加载失败恢复。在线专项需要访问 OpenStreetMap。
