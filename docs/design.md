# 校园植物游园：界面改版

## 目标

保留植物地图、分类、检索、变迁、文章和留言入口，改进阅读层次与查找路径。参考 PhoneticToolbox 的圆润、轻盈和立体感，以叶绿为主色，白色与深绿色形成层次，少量花瓣粉作点缀，不使用黄色界面元素。真实校园摄影与透明植物插画分别承担资料展示和首页装饰。

## 主要改动

- 首页插画轻轻漂浮、随鼠标摆动，可暂停。植物卡片可点选，支持方向键。按钮按下、卡片浮起、滚动显现和页面切换有反馈，遵循减少动画偏好。
- 紧凑导航、清晰的当前页状态、移动端菜单与键盘焦点。
- 导航全宽贴顶并使用不透明背景，统一导航高度、吸顶侧栏、阅读进度和章节滚动位置，取消原有悬浮间隙。
- 外观默认跟随系统，可手动选择浅色、深色并保存在当前浏览器。深色使用石墨灰背景与灰色卡片，叶绿作为操作和文字强调色，保留原始照片与插画色彩。
- 地图默认使用 OpenStreetMap 深色呈现，保留标准底图。替换目前返回 API KEY REQUIRED 的 CARTO 图源。Canvas 绘制所有点位，支持搜索、科筛选、回到全图和展开。
- 检索首次加载显示图鉴，搜索与科筛选可组合，查询写入 URL，结果可直接查看详情或地图。
- 分类树增加筛选、选中反馈、加载与错误重试，选择植物展示照片、分类和分布。
- 通读 10 篇文章并逐篇绘制封面，文章以主次分明的封面目录与独立阅读区呈现，保持原文、命名与拉丁学名格式。阅读字号、图片宽度与行距支持调整和本地保存。
- 变迁按年份分组。静态联系页采用白色信笺与深绿公众号卡片，支持复制邮箱；动态留言保留表单与状态反馈。
- 手机图鉴压缩标题与筛选区，在首屏展示完整照片。
- 拼接照片通过单张视窗呈现，档案、分类、检索和首页统一支持滑动与点击看大图。档案信息卡调整为白色，照片区以深绿底衬托。
- 首页与地图侧栏每天随机选取物种，相识卡片随机选四种，提供换一组。
- README 配真实桌面和移动截图，说明启动、数据、目录、静态与动态模式及验证范围。
